# Mock ADVS spec

An 11-variable mock BDS spec (USUBJID, PARAMCD, PARAM, AVAL, AVALU,
AVISIT, ABLFL, BASE, CHG, PCHG, ANRIND) exercising lookup joins,
baseline flags, change-from-baseline arithmetic, and reference-range
categorisation.

## Usage

``` r
mock_spec_advs()
```

## Value

A spec data frame as produced by \[read_spec_df()\].
